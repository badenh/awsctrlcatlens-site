awsctrlcatlens

awsctrlcatlens is an automatically-refreshed, machine-generated index over the AWS Control Catalog. AWS exposes a list of controls through controlcatalog:ListControls, but not the questions that security and compliance engineers and cloud architects actually ask: which controls are deployable in which region, which controls govern this service, how do controls map to security frameworks, which controls share a single intent but multiple sources?

This site answers those questions.

Raw controls from Security Hub, AWS Config, CloudFormation Hooks, and AWS Organizations SCPs are canonicalised into a single node by technical security outcome intent. All controls are cross-indexed by region, service, and framework, and refreshed from the live AWS Control Catalog API on a scheduled run.
