    Glossary

    TermDefinition
    canonical A single conceptual control after collapsing cross-executor duplicates (Security Hub + Config + CloudFormation hook) into one node.
    control An individual AWS Control Catalog entry — one ARN, one implementation (Security Hub, Config, or hook).
    variant A single raw control that is a member of a canonical group. Each canonical typically has 1-3 variants.
    framework item A single clause/requirement inside a compliance framework (e.g. PCI-DSS-v4.0 7.2.1).
    common control A reusable sub-control (e.g. CC1.1) that AWS maps multiple framework items to; used as a bridge to infer indirect cross-framework overlap.
    veto A guard that prevents two candidate variants from merging into one canonical (e.g. V1 antagonist token clusters, V4 disjoint services).
    crosswalk The mapping from one framework's item to equivalent items in other frameworks via a shared canonical.
    tombstone A canonical_id reserved permanently after its underlying controls disappear from the catalog — the ID is never reused for a different concept.
    impl type The AWS implementation surface of a variant: Security Hub, AWS Config rule, or CloudFormation hook.
    severity AWS-assigned severity label (CRITICAL / HIGH / MEDIUM / LOW) attached to a control.
    behavior AWS-assigned behavior label: PREVENTIVE (blocks noncompliant actions before they happen), DETECTIVE (flags noncompliance after it happens), or PROACTIVE (evaluated at change-request time, e.g. CloudFormation hooks).
    executor family The AWS surface that implements a raw control: config (AWS::Config::ConfigRule), securityhub (AWS::SecurityHub::SecurityControl), cfnhook (AWS::CloudFormation::Type::HOOK), or organizations (AWS::Organizations::Policy::* — SCP, RCP, and declarative policies).
    SCP Service Control Policy. An AWS Organizations policy applied at the account or OU level that denies specified IAM actions regardless of what inline / managed policy a caller holds.
    RCP Resource Control Policy. The resource-side counterpart to an SCP; attaches to a resource and denies specified actions on it regardless of the caller's permissions.
    opt-in region An AWS region that is not enabled on a new account by default; must be explicitly enabled per account. Derived from account:ListRegions RegionOptStatus field: anything other than ENABLED_BY_DEFAULT is opt-in.
    GovernedResources A list field on each GetControl response naming the CloudFormation resource types the control evaluates (e.g. AWS::S3::Bucket). We use the second ::-chunk of the first entry as the authoritative service namespace.
    degree Graph degree in the canonical projection graph: the count of unique neighbour canonicals a given canonical is connected to via direct related edges or shared common controls.
    framework count The number of distinct compliance frameworks a canonical appears in. One of the two signals (alongside degree) on the Analysis page.
    composite score degree × framework count per canonical. Used as the sort signal for the long-tail histograms on the Analysis page.
    hub A canonical with unusually high degree — connected to many other canonicals via related edges or common-control bridges. Hubs are compliance-coverage leverage points.
    Jaccard Set-intersection size divided by set-union size, scaled 0..1. Used pairwise on frameworks' canonical-ID sets to score framework similarity on the Analysis heat map.
    density On a framework page: mapped-rows ÷ unique canonicals. Density > 1 means AWS maps the same canonical to multiple items in that framework (maturity tiers, pillar overlap, cross-domain mapping).
    snapshot A single dated capture of the AWS Control Catalog plus every derived index for one refresh. Site builds are a pure function of a single snapshot.
    sealed A snapshot is sealed once the refresh has written every artifact and emitted its provenance manifest. Only sealed snapshots are published to the site.
