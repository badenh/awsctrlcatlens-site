    About this framework

    The AWS Foundational Security Best Practices is an AWS-authored security standard published by AWS Security Hub. The standard, its control membership, and all control text are the intellectual property of Amazon Web Services, Inc. and its affiliates. This page is a derived view: awsctrlcatlens overlays the standard's control membership onto the AWS Control Catalog's canonical controls to expose per-region deployability, per-service grouping, and cross-framework crosswalk — none of which are published in the Security Hub standard directly.
